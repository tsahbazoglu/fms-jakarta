=== Maven Version Management Commands

Use the following Maven commands when updating or rolling back project versions:
[source,bash,js,subs="attributes,verbatim,quotes"]
Automatically update all submodule parent references to match the root POM version

mvn versions:update-child-modules
Commit the version changes permanently (removes backup files)

mvn versions:commit
Revert version changes and restore original files if needed
mvn versions:revert
