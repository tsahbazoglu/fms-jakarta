Mühürdar eimza uygulama kurulumu:
  • http://java.com sayfası üzeriden bilgisayarınıza güncel Java sürümünü kurunuz
  • muhurdar-agent-2.0.0-Final-installer.jar bağlantısı üzerinden indirilen kurulum dosyasını çalıştırınız

İmzalama İşlemi
  • Eimza Kartınızın takılı olduğundan emin olunuz
  • İmzala düğmesine basıldığında imzalanmak üzere *.mhr uzantılı bir dosya bilgisayarınıza indirilecek
  • İndirilen dosya üzerine tıklayınız
  • Bu aşamadan sonra Akıllı Kartınızı kullanarak dosyayı imzalayıp tarafımıza gönderebilirsiniz
