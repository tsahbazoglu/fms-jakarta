== Compilation and Deployment

To accelerate the deployment phase, we first perform a standalone compile with `compile` scope to extract and migrate core libraries to the GlassFish global library directory. Subsequent builds use the `provided` scope to create a lightweight EAR file, significantly reducing deployment time during active development.

=== Standalone Compile
[source,js,subs="attributes,verbatim,quotes"]
----       
cd {project_path}
mvn clean install -Ddependency.scope=compile
----

=== Standalone compile + E-sign Support
[source,js,subs="attributes,verbatim,quotes"]
----
cd {project_path}

mvn clean install -PesignOyas -Ddependency.scope=compile

mvn clean install -PesignKamusm -Ddependency.scope=compile

----

=== Library Migration (GlassFish)

Extract the libraries from the EAR and move them to the domain library folder to avoid redundant bundling:

==== Navigate to deployment target
[source,js,subs="attributes,verbatim,quotes"]
----  
cd {project_path}/fms-ear/target/

jar -xvf fms-ear-{project_version}.ear

ls -lrt lib/*.jar
----

==== Deploy fresh libraries
[source,js,subs="attributes,verbatim,quotes"]
----
cp lib/*.jar {server-path}/domains/domain1/lib
----

==== Remove project-specific libraries from the local path to prevent JAR confusion
[source,js,subs="attributes,verbatim,quotes"]
----
# FMS Jars
rm -rf {server-path}/domains/domain1/lib/fms-*

# Muhurdar Jars
rm -rf {server-path}/domains/domain1/lib/muhurdar-*

# MA3API Jars
rm -rf {server-path}/domains/domain1/lib/ma3api-cmssignature-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-infra-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-crypto-sunprovider-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-common-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-smartcard-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-signature-{ma3api-version}.jar
rm -rf {server-path}/domains/domain1/lib/ma3api-crypto-{ma3api-version}.jar

== About

FMS (Form Management System) project is aimed to accelerate development and deployment process of widely used form types like registration forms, tables and pivot input.

All you need to do is accustom the configuration script file to your needs and import it to mongodb.

You will get both the data structure and Web GUI in one shot.

Check out our live project configuration files to discover all the features.

----
# if domain stopped

# if domain started
asadmin create-jvm-options --add-exports=java.base/sun.security.pkcs=ALL-UNNAMED
asadmin create-jvm-options --add-opens=java.base/sun.security.pkcs=ALL-UNNAMED

asadmin create-jvm-options --add-exports=java.base/sun.security.x509=ALL-UNNAMED
asadmin create-jvm-options --add-opens=java.base/sun.security.x509=ALL-UNNAMED
