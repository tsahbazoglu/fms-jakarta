== CLI
----
agy --help
agy --mode=accept-edits
agy --auto-execute

# To exit safely from the TUI (Terminal User Interface):
/quit

# To temporarily suspend/drop back to your host shell:
Ctrl+Z

# Resuming a Session
agy -c
agy --continue
agy --conversation <session_id>
----

== Setting Attribute
----
"autoExecute": true - Yes, Run Command
"agentMode": "accept-edits" - Yes, Edit
----
